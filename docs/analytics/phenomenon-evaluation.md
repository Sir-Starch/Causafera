# Phenomenon Evaluation

The project must measure emergence rather than merely admire random output. The phenomenon evaluation framework provides metrics for assessing the quality and depth of emergent phenomena.

## Metrics

### Causal Depth

Number of meaningful causal stages between origin and observed phenomenon.

### Domain Coupling

Number of distinct subsystems participating in the phenomenon.

### Local Specificity

Dependence on specific geographic or historical conditions. Would the same phenomenon arise in a different location?

### Path Dependence

Sensitivity to early history. Would a small change in initial conditions prevent the phenomenon?

### Counterfactual Sensitivity

Whether removing a specific cause changes the phenomenon.

### Subjective Divergence

Number and strength of incompatible explanations held by different agents or groups.

### Temporal Span

Time between early cause and visible outcome.

### Emergent Novelty

Distance from predefined observer categories. How surprising is the phenomenon relative to expected outcomes?

### Reconstructability

Quality of recoverable provenance. Can the causal history be traced with confidence?

## Evaluation Process

Phenomenon evaluation should be applied to:

- unexpected simulation outcomes;
- target emergent phenomena (Status, classes, dungeons, etc.);
- historical developments;
- social institutions;
- magical effects.
