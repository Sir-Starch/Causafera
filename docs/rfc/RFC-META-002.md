# RFC-META-002: Stateful Mana Attractors

**Status:** Accepted

## Summary

Phase 23 accepts a bounded read-only research architecture for testing the stateful-attractor hypothesis. It does not add an attractor entity, god, spirit, artifact, semantic mana type, or belief-sensitive field rule.

## Research observations

`FieldTrajectoryObservation` records only:

- simulation time;
- canonical field-state fingerprint;
- total and maximum non-negative magnitude;
- number of changed components;
- one supporting committed trace.

`AttractorProbe` is identified by an opaque schema and contains numeric stability and recovery tolerances. Given a canonical observation sequence and an optional perturbation boundary, it reports:

- observation span;
- stable-transition count;
- transition count;
- post-perturbation recovery distance and tolerance comparison, when available;
- canonical supporting traces.

The result is evidence about a trajectory. It is not an instantiated object and does not claim agency, intention, reproduction, divinity, spiritual identity, or semantic responsiveness.

## Phase 24 executable experiment

The first headless causal runtime commits a physical repeated carrier, evolves the existing fixed-point mana field, and converts committed mana changes into an opaque causal-resolution signal. The lab runs replay-verified control and temporary carrier-suppression trajectories and records bounded checkpoints.

This establishes an executable test bed for persistence and perturbation questions. A difference between trajectories is evidence of causal sensitivity, not proof of an attractor or emergent being.

## Semantic exclusion

Mana still cannot inspect beliefs, concepts, words, prayers, practices, organizations, identities, observer labels, or experiment names. CLI labels select developer workflows only and never enter authoritative state.

## Determinism and performance

All authoritative evolution uses fixed-point/integer arithmetic, canonical scheduler phases, proposal/commit semantics, and committed traces. Probe evaluation is read-only and bounded. Wall-clock duration is report-only and excluded from replay equality. No scale or emergence claim is made.

## Decisions

- **Accepted:** numeric field-trajectory observations and opaque read-only probes.
- **Accepted:** stability and perturbation recovery as evidence dimensions.
- **Accepted:** control/intervention replay as the first long-run research workflow.
- **Rejected:** primitive gods, spirits, artifacts, souls, semantic attractor categories, or belief-reactive mana.
- **Deferred:** cross-chunk fields, concrete acoustic/material/biological adapters, field-to-matter effects, autonomous persistence mechanisms, phenomenon mining, and final attractor criteria.
