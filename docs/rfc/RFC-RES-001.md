# RFC-RES-001: Causal Resolution and State Aggregation

**Status:** Proposed

## Summary

Simulation resolution depends on causal relevance, not only physical distance.

## Motivation

Support detailed simulation of causally connected distant regions while aggregating nearby but irrelevant regions.

## Details

To be developed during Phase 15.

## Unresolved Questions

- Relevance dimensions
- Aggregation criteria
- Transition smoothness
