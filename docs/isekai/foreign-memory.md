# Foreign Memory

Foreign memory is the information that a transferred agent retains from their origin world. It is not a complete and accurate record of their previous life. It is a partial, reconstructed, and often distorted set of associations that may or may not be useful in the new world.

## What Survives Transfer

Phase 22 records any surviving cognitive influence as an `ImportedPriorBundle`: subjective pattern IDs, weights, subjective source identity, and the committed transfer trace. It does not assert that a memory is accurate, install Ground Truth identity, or directly mutate ordinary cognition stores.

The following may survive cross-world transfer, depending on transfer type:

- **Declarative knowledge** - Facts, propositions, theories
- **Procedural knowledge** - Skills, techniques, methods
- **Perceptual expertise** - Pattern recognition abilities
- **Motor skill** - Physical action patterns (may not map to new body)
- **Emotional associations** - Feelings without clear remembered causes
- **Social knowledge** - Understanding of relationships, institutions, norms (may not apply)
- **Language** - Source-world language competence (may be useless locally)

## What Is Lost

The following may be lost or degraded:

- **Contextual knowledge** - When, where, and how something was learned
- **Source provenance** - Whether a memory is firsthand, hearsay, or fiction
- **Temporal ordering** - The sequence of events
- **Specific details** - Names, dates, precise measurements
- **Embodied knowledge** - Knowledge tied to the specific body left behind
- **Social connections** - Relationships with people who did not transfer

## Memory and Development

An isekai-born child retaining foreign memory may interact with local concept acquisition differently from an adult physical transfer:

- The child's developing brain integrates foreign and local concepts
- Foreign memories may emerge gradually rather than all at once
- The child may not distinguish foreign from local memories
- Local language acquisition shapes how foreign concepts are expressed

## Memory and Identity

Foreign memory raises identity questions:

- Is the transferred agent the same person as the source-world individual?
- If memories are partial, is the resulting agent a continuation or a copy?
- If multiple identity patterns overlap, how many agents are present?

These are metaphysical questions, not questions with predetermined simulation answers.
