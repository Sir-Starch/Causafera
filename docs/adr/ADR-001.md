# ADR-001: Rust as Implementation Language

**Status:** Accepted

## Context

Ontopolis requires high performance, deterministic execution, and strong type safety for a complex simulation.

## Decision

Use stable Rust with edition 2024.

## Consequences

- Strong memory safety guarantees
- Excellent performance characteristics
- Mature ecosystem for systems programming
- Steeper learning curve for contributors

## Alternatives Considered

- C++: Rejected due to memory safety concerns
- Go: Rejected due to GC non-determinism
- Zig: Rejected as immature ecosystem
