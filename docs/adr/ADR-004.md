# ADR-004: Headless Simulation with Observer Layer

**Status:** Accepted

## Context

The simulation must remain authoritative and headless, with UI as a separate concern.

## Decision

Simulation is headless. UI communicates via Protocol Buffers over an observer API.

## Consequences

- UI cannot directly access simulation state
- UI cannot mutate simulation state
- Observer data is derived and versioned
- Network overhead for local UI

## Alternatives Considered

- Embedded UI: Rejected due to coupling
- Direct memory sharing: Rejected due to safety
