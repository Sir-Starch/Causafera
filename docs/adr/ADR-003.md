# ADR-003: Deterministic Random Streams

**Status:** Accepted

## Context

Reproducibility is essential for testing, replay, and causal analysis.

## Decision

Use explicit deterministic random streams with hierarchical seeding.

## Consequences

- Strict mode for testing and replay
- Fast experimental mode with weaker guarantees
- Parallel scheduling must be order-independent for random outcomes

## Alternatives Considered

- System random: Rejected due to non-determinism
- Seeded global RNG: Rejected due to ordering sensitivity
