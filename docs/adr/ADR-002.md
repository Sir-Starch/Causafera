# ADR-002: Cargo Workspace with Domain Crates

**Status:** Accepted

## Context

The simulation has many distinct domains (biology, language, geography, etc.) with different stability and expertise requirements.

## Decision

Use a Cargo workspace with ~20 domain-specific crates.

## Consequences

- Clear domain boundaries
- Independent compilation units
- Enforced dependency direction
- Some overhead in crate management

## Alternatives Considered

- Single crate: Rejected due to poor separation
- Microcrate approach: Rejected due to excessive overhead
