# ADR-006: Protocol Buffers for Observer Protocol

**Status:** Accepted

## Context

The observer protocol needs versioning, efficiency, and multi-language support.

## Decision

Use Protocol Buffers with versioned schemas under `proto/causafera/observer/v1/`.

## Consequences

- Strong schema versioning
- Efficient binary serialization
- Multi-language code generation
- Build complexity for proto generation

## Alternatives Considered

- JSON: Rejected due to size and speed
- FlatBuffers: Rejected due to smaller ecosystem
- Custom binary: Rejected due to maintenance burden
