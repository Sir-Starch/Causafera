# ADR-005: Tauri + React + WebGPU for Desktop UI

**Status:** Accepted

## Context

The observer UI needs rich panels, maps, and large dataset visualization.

## Decision

Use Tauri for the desktop shell, React for UI panels, and WebGPU for map/spatial rendering.

## Consequences

- Modern web technology stack
- WebGPU for GPU-accelerated visualization
- pnpm workspace for monorepo management
- Some complexity in Rust/JS bridge

## Alternatives Considered

- Native Rust UI: Rejected due to immature ecosystem
- Electron: Rejected due to bundle size and performance
