# Target Emergent Isekai Phenomena

The following familiar fantasy and isekai phenomena are target emergent outcomes:

- Status Window
- levels
- skills
- classes
- adventurer guilds
- monster taxonomy
- dungeons
- artifacts
- magical schools
- magical contracts
- gods
- spirits
- reincarnation doctrines
- summoned heroes
- sacred languages

## They Must Not Be Primitive Engine Systems

Bad:

```text
enum Class {
    Warrior,
    Mage,
    Rogue
}
```

## Preferred Historical Process

```text
social category
→ standardized training
→ shared equipment
→ synchronized practices
→ local mana coupling
→ stable characteristic effects
→ institutional classification
→ later Status-system representation
```

The simulation may eventually produce a concept functionally similar to a class.

The engine does not start with `Class`.
