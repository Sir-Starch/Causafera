# Cross-World Continuity

Cross-world continuity is the question of whether and how identity, memory, or pattern persists when an entity moves between worlds. It is a metaphysical research question at the intersection of isekai transfer and identity theory.

## The Continuity Problem

When something crosses from one world to another, what makes the result the same entity as the original?

- If a body is physically transported, is it the same person?
- If a body is left behind and a copy created, is the copy the same person?
- If only memories transfer, do they constitute the same person?
- If an identity pattern binds to a new body, is the result one person or two?

## Candidate Continuity Criteria

### Physical Continuity

The same matter moves from one world to another. The entity is continuous because its physical substrate is continuous.

Problems:

- Matter is constantly exchanged with environment
- Bodies repair and replace components
- What if only part of the matter transfers?

### Psychological Continuity

The same memories, personality, and cognitive patterns continue. The entity is continuous because its mental content is continuous.

Problems:

- Memories change and degrade
- Personality shifts over time
- What if psychological continuity is partial?

### Pattern Continuity

A stable information pattern persists. The entity is continuous because a defining pattern continues, regardless of substrate.

Problems:

- What counts as the defining pattern?
- Patterns can be copied
- What if multiple copies exist?

### Causal Continuity

There is an unbroken causal chain from the original to the result. The entity is continuous because its history is continuous.

Problems:

- Causal chains branch
- Causal chains can be interrupted and resumed
- What if causal continuity is mediated by a third party?

## Research Status

Phase 23 accepts a research architecture in which opaque evidence channels feed multiple explicit weighted criteria. The result remains a set of numeric criterion scores with causal traces. Transfer payload correspondence is possible evidence, not proof that one person continued. No final metaphysical model is selected.
