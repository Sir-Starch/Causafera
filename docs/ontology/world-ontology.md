# World Ontology

Ontopolis requires an explicit ontology to prevent entire domains from being forgotten or implemented as semantic shortcuts. The ontology system ensures every fundamental domain is consciously designed before entering implementation.

## Ontology Documentation

The ontology layer contains:

- **Domain Coverage Matrix** - Mandatory coverage analysis for every domain
- **Causal Carriers** - Documentation of what carries causal influence
- **Lifecycle Audit** - Complete lifecycle tracking for all persistent entities
- **Cross-Domain Interactions** - Matrix of plausible interactions between domains
- **Primitive vs Emergent** - Clear boundary between engine primitives and human concepts
- **Unresolved Assumptions** - Explicitly documented gaps and research hypotheses

## Domain Coverage Requirements

Every fundamental domain must answer fourteen questions before implementation:

1. What objectively exists?
2. Where is authoritative state stored?
3. What processes modify it?
4. What moves or propagates?
5. How can the state be physically observed?
6. How may agents conceptualize it?
7. How can information about it spread?
8. How is it represented under causal resolution?
9. How is provenance preserved?
10. How is it exposed to the observer layer?
11. What are its performance risks?
12. What are its deterministic requirements?
13. Which other domains can it affect?
14. Which other domains can affect it?

A foundational domain cannot enter implementation without coverage analysis.

## Lifecycle Audit

For every persistent entity or phenomenon, the architecture must account for:

- origin
- development
- stable operation
- interaction
- transmission
- degradation
- transformation
- death / destruction
- historical residue

Example: a building requires tracking through construction, material provenance, use, maintenance, modification, damage, abandonment, collapse, reuse, and archaeological residue.

## Cross-Domain Consciousness

Not every possible pair of domains requires implementation. Every pair must at least be consciously considered. The cross-domain interaction matrix records plausible interactions such as language affecting mana through acoustic recurrence, or geology affecting economy through material availability.

## Ontology and Implementation

The ontology layer is not a specification for immediate implementation. It is a constraint system that prevents:

- semantic enums replacing emergent concepts
- entire domains entering code without analysis
- developer convenience overriding causal fidelity
- English labels becoming authoritative simulation state

See the Domain Coverage Matrix for current domain status and phase assignments.
