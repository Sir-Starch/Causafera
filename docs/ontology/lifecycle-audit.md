# Lifecycle Audit

For every persistent entity or phenomenon, document:

```text
origin
development
stable operation
interaction
transmission
degradation
transformation
death / destruction
historical residue
```

## Example: Building

A building must not merely exist.

The architecture must eventually account for:

```text
construction
material provenance
use
maintenance
modification
damage
abandonment
collapse
reuse
archaeological residue
```

## Example: Practice

```text
invention or discovery
initial adoption
standardization
institutional embedding
transmission to new practitioners
modification through error or drift
conflict with competing practices
abandonment
fossilized residue in language or records
```

## Example: Social Category

```text
perceived pattern
naming
institutional use
legal codification
intermarriage or exclusion
spatial concentration
economic consequences
historical residue in records and buildings
```
