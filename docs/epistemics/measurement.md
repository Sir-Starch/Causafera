# Measurement

Measurement is the process by which agents assign quantitative values to properties of the world. It is a fundamental epistemic activity that enables comparison, prediction, and technological control.

## Measurement as Social Practice

Measurement is not merely reading a value from nature. It involves:

- Choosing what to measure
- Defining a measurement procedure
- Selecting or creating a unit
- Calibrating against a standard
- Recording the result
- Assessing error and precision

Each of these steps is socially situated and may vary across communities.

## Measurement Properties

Individual measurements have:

- **Value** - The numerical result
- **Unit** - The standard against which the value is expressed
- **Precision** - The fineness of discrimination
- **Error** - The likely deviation from true value
- **Calibration provenance** - The chain of standards back to a reference

## Measurement and Magic

In a pattern-sensitive magical world, measurement practices may unintentionally create mana-relevant structures:

- Repeated standardized measurements create temporal recurrence
- Mass-produced measuring tools create identical physical patterns
- Calibration rituals create synchronized practices
- Standardized units create consistent symbolic structures

A standardization reform may alter repeated industrial patterns and thereby alter local mana conditions.

## Measurement Types

The architecture must support measurement of:

- Length
- Mass
- Time
- Temperature
- Frequency
- Mana-related measures

Different societies may use different units and calibration practices for each type.

## Implemented Foundation

`causafera-epistemics::measurement` represents quantity and unit identity opaquely. Units have rational integer scale and resolution. Calibrations record parent ancestry, systematic bias, uncertainty, time, and the practice used. A result is derived from an accessible observation and retains combined uncertainty; the API has no hidden Ground Truth value parameter.
