# Support

Causafera is an author-led free and open-source causal world-simulation engine
(**Experimental pre-alpha**). It has no support SLA, stable public API, save-format compatibility
promise beyond documented contracts, hosted service, or playable release.

Use the GitHub issue templates for:

- reproducible defects in the current `main` branch;
- documentation errors;
- bounded capability proposals that respect the architecture invariants.

Before filing an issue, search existing issues and include the commit SHA, operating system,
toolchain versions, commands run, expected result, actual result, and a minimal reproduction. Redact
credentials, personal data, local paths, and private logs.

Questions that require design work may be closed or redirected until an accepted ExecPlan exists.
As Causafera is an engine rather than a consumer game, end-user gameplay suggestions and high-level
scripted-world features fall outside current priorities, though active engine development continues.

Scope and direction are decided by the maintainer rather than by consensus, so a proposal may be
declined because it does not fit the project's vision even when it is technically sound. See
[`GOVERNANCE.md`](GOVERNANCE.md) for how those decisions are made and what to do if you disagree,
and [`CONTRIBUTING.md`](CONTRIBUTING.md) for the contribution flow and the current status of the
CLA acceptance workflow.

Security vulnerabilities and accidental secret exposure must not be reported publicly. Follow
[`SECURITY.md`](SECURITY.md).
